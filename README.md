# VietNam-Stock-Dashboard
Vietnam Stock Market Analytics
A Python-based website for analyzing stocks listed on the Vietnamese stock market.

## Features (Planned)

- Historical stock prices and returns
- Statistical analysis (mean, median, volatility, etc.)
- Interactive stock charts
- Correlation analysis between stocks
- Portfolio optimization and asset allocation
- Portfolio backtesting

## Technologies

- Python
- Streamlit
- pandas, NumPy, SciPy

## Project Status

Under development.
